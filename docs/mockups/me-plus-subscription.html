以目前的 app/src/templates/application/Me/ 實作為底（1 張卡內嵌 Profile、2 張以上拆出「訂閱特權」bubble）， 只加 Plus 的樣式與「被 Plus 覆蓋的月卡」樣式。Progress bubble 全部情境都不變，以虛線框代替。
福利數字：月卡 +1 抽 / 200 石、季卡 +2 抽 / 500 石（與 app/seeds/SubscribeCardSeeder.js 及線上一致）、Plus +2 抽 / 500 石。

元件 → Flex 結構對照

元件 Flex 結構
Plus 面板頂端紫→金細線 沿用 buildAccentBar：box height 3px， background: { type: "linearGradient", angle: "90deg", startColor: "#A834FF", endColor: "#FCD34D" }， backgroundColor 放 #A834FF 當舊版 fallback。
Plus 面板底色 HERO_SURFACE.bgRaised（#1A2E4A）取代 bgAlt，比其他卡亮一階，其餘 padding / spacing 與 buildSubPanel 相同。
「月卡 Plus」tag 跟現有 tagChip 同結構（box + text xxs bold，cornerRadius sm），bg RARITY.epic.main、字色 #FFFFFF（對比約 4.6:1）。
Plus 專屬福利列 單一 text + 3 個 span：◆ （amber400 bold）＋ 福利文字（heroText）＋ Plus 專屬（#D8B4FE bold）。不用額外 box。
被覆蓋的月卡 headRow 結構不變，只換色：hairline 改純色 HERO_SURFACE.bgButton（#2D4068，不給漸層），tag bg 同色、字色 heroTextMuted。 福利列整段拿掉，換成一行 text（xxs、heroTextMuted、wrap: true）。Flex 沒有 opacity，所以「變淡」一律用換色做。
訂閱特權 header 右側 現有 text 換文字而已：有暫停卡時顯示「N 張・M 張暫停」，否則維持「N 張啟用中」。
Profile 的訂閱 badge 沿用 buildSubBadge / buildLinkPill（無圓角、無 action），文字依新排序 join。3 張最長「🎟 訂閱中 · 月卡 Plus + 季卡 + 月卡」約 20 字，xxs 在 mega 寬內放得下不會被截斷。

實作時要動的地方（僅記錄，這次不改 code）

  • ChatLevelController.js:159 的 subscriptionRank：改成 生效中的卡在前、被覆蓋的卡在後， 即 month_plus → season → month；只有月卡或月卡+季卡時排序跟現在一樣。
  • 卡片資料多兩個欄位：paused: boolean（持有 Plus 時月卡為 true），effects 從 string[] 改成 { text, exclusive }[]（或在 template 內用 effect type 判斷），讓 template 知道哪一列要加「Plus 專屬」。
  • buildSubPanel 依 key === "month_plus" / paused 分三種樣式；Subscription.build header 計算暫停張數。暫停提示依到期日二選一：月卡 end_at 晚於 Plus end_at 用 paused_by_plus_resume，否則（早於或同一天）用 paused_by_plus_expire。
  • locale：message.subscribe.month_plus、effects.auto_janken_match（名稱暫定，依實際 effect type 命名）、暫停提示、header 計數。
  • 高度：Plus 單卡內嵌讓 Profile 比現在月卡內嵌多約 50px（多 3 列福利），仍在 mega 可接受範圍；3 張卡的訂閱特權 bubble 約 300px，比 Profile 矮。
